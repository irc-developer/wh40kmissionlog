# Terminal de misión

Web pensada para móviles, con estética de terminal táctico, para que un operador lleve ambos jugadores de una partida de Warhammer 40K desde un único dispositivo.

Su objetivo es facilitar el seguimiento de la partida: preparar a los jugadores, gestionar misiones y secundarias mediante mazos digitales, registrar puntuaciones y consultar el marcador, la ronda y el turno. Incluye correcciones, deshacer y guardado automático para recuperar la partida en curso, además de funcionamiento sin conexión tras la descarga inicial.
